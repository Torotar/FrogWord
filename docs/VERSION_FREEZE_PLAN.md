# WordFlowHarmony 1.0.0 版本冻结计划

## 冻结范围

版本号：`1.0.0`

冻结后只允许：

1. 修复 bug。
2. 优化性能。
3. 修复 UI 兼容问题。
4. 补充测试。
5. 补充发布文档。

冻结后不再新增：

1. 云同步。
2. 账号系统。
3. 会员系统。
4. 广告。
5. 新的大型业务模块。
6. 大规模 UI 重构。

## Bug 优先级

P0：阻塞发布

1. App 无法启动。
2. 数据库初始化失败。
3. 学习记录无法保存。
4. release 包无法安装。
5. API Key 泄露风险。

P1：发布前必须修

1. 首页统计不刷新。
2. 复习筛选错误。
3. 设置保存失败。
4. 文件导入导致崩溃。
5. 深色模式严重不可读。

P2：可随版本修复

1. 个别页面间距不统一。
2. 非核心文案不准确。
3. 弱网提示可读性一般。
4. 特定机型布局轻微偏移。

P3：延后到 1.1.0

1. 音频缓存。
2. 更完整的词书编辑。
3. 更复杂的统计图表。
4. 自动化测试覆盖率提升。
5. 全局主题细节增强。

## 发布前最后 3 天计划

第 3 天：

1. 完整跑 UI 冒烟测试。
2. 真机覆盖首次安装、升级安装、清除数据后启动。
3. 检查数据库初始化和默认词库。
4. 修复 P0 / P1 问题。

第 2 天：

1. 打 release 包并安装到真机。
2. 测试 AI、在线发音、导入、搜索、学习、复习。
3. 检查隐私政策、权限说明、应用图标、版本号。
4. 关闭 debug 日志和 Debug 页面入口。

第 1 天：

1. 冻结代码。
2. 清空测试 API Key。
3. 生成最终 HAP / APP 包。
4. 做最终冒烟测试。
5. 准备应用截图、介绍文案、隐私声明和发布记录。
