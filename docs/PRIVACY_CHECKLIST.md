# WordFlowHarmony 隐私与合规检查清单

## 是否需要隐私政策

需要。即使 1.0.0 以本地学习为主，App 仍涉及学习记录、导入词书、AI API Key、第三方网络请求和在线发音接口，发布前应提供隐私政策。

## 数据说明

1. 学习记录保存在本机数据库中，用于展示学习进度、复习计划和统计。
2. 用户导入的词书文件仅用于本地解析和写入本机数据库。
3. AI API Key 仅保存在本机 Preferences 中，不应上传到自有服务器。
4. 用户主动点击 AI 解释或测试接口时，单词内容会发送到用户配置的第三方 AI 接口。
5. 在线发音功能会请求第三方发音 URL，用于播放单词读音。
6. 默认情况下不会上传用户词书内容，除非用户主动对某个单词调用 AI 解释。
7. 网络权限用于 AI 接口测试、AI 解释和在线发音。
8. 用户可以通过系统清除应用数据，或在 App 内重置学习记录。

## API Key 安全

1. 不在日志中输出 API Key。
2. 不把 API Key 写入代码仓库。
3. 不在截图、演示视频、测试报告中暴露真实 Key。
4. Debug 日志关闭后再打 release 包。

## 第三方接口提示

隐私政策中应说明：

1. AI 请求会发送到用户填写的 Base URL。
2. 在线发音请求会访问有道发音地址或后续配置的发音服务。
3. 第三方服务的数据处理规则以对应服务提供方政策为准。

## 数据清除

建议在正式版本中提供清除数据入口：

1. 清除学习记录。
2. 删除导入词书。
3. 清除 AI API Key。
4. 恢复默认设置。

第五阶段已提供 DebugDatabasePage 供开发调试，正式版应隐藏开发入口。
